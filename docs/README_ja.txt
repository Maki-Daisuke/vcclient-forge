1. 起動方法
----------------------------------------------------------------------

※ cuda 版をご利用の場合（Windows / Linux 共通）:
   あらかじめ NVIDIA GPU ドライバを最新版へアップデートしてお使いください
   （CUDA 13 対応の R580 以降が必要です）。CUDA Toolkit と cuDNN は同梱
   されているため、別途インストールする必要はありません。

Windows
-------

【デスクトップ版（おすすめ）】

"vcclient-forge.exe" をダブルクリックしてください。

【Web ブラウザ版】

"start.bat" をダブルクリックしてください。
ブラウザが自動的に開き、以下の URL にアクセスします:
http://localhost:18888/

macOS
-----

【デスクトップ版（おすすめ）】

初回起動時: このフォルダでターミナルを開き、以下を実行してください:

  sh MacStart.command

※2回目以降は、Finder から "MacStart.command" をダブルクリックするだけで起動できます

【Web ブラウザ版】

このフォルダでターミナルを開き、以下を実行してください:

  ./start.sh

ブラウザが自動的に開き、以下の URL にアクセスします:
http://localhost:18888/

Ubuntu Linux
------------

【動作要件・依存ライブラリ】

- OS: Ubuntu 24.04 LTS 以降（glibc >= 2.39）
- デスクトップ版とローカル音声（Server Mode）に必要なパッケージ:

  sudo apt-get update && sudo apt-get install -y libportaudio2 libwebkitgtk-6.0-4 7zip

【デスクトップ版（おすすめ）】

ターミナルで "./vcclient-forge" を実行してください。

【Web ブラウザ版】

ターミナルで "./start.sh" を実行してください。デスクトップ環境では
ブラウザが開き、http://localhost:18888/ にアクセスします。
ヘッドレスサーバーでは "./main" を実行し、用意したリモート接続経由で
ブラウザからアクセスしてください。ブラウザで音声を扱う Client Mode
では、バックエンド側に音声サーバーは不要です。

【Linux の WebGPU アクセラレーション（実験的機能）】

動作する Vulkan GPU ドライバーと Vulkan ローダー（libvulkan.so.1）が
必要です。Ubuntu では libvulkan1 がローダーを提供します。変換を停止した
状態で、設定画面から [WebGPU] デバイスを選ぶか、自動選択を実行してください。

----------------------------------------------------------------------
2. 旧版 Forge または w-okada VC v2.0.78 からの移行
----------------------------------------------------------------------

旧版を終了し、"settings" と "model_dir" をバックアップしてください。
新しく展開した Forge のフォルダに両方をコピーしてから起動します。
数字で管理されていたモデルフォルダは、初回起動時に catalog.json を使う
NanoID 形式に移行されます。旧版では移行後の形式を読み込めません。
旧版に戻す場合は、元のインストール先を使うか、両方のバックアップを
復元してください。

----------------------------------------------------------------------
3. 初回起動時のご注意
----------------------------------------------------------------------

起動時に、不足している RVC モジュール（ContentVec、ピッチ推定器など）を
ダウンロードします。モデルカタログが空の場合は、サンプル音声モデルも
ダウンロードします。
通信環境によってはダウンロード完了まで数分程度お時間がかかりますので、
画面が開くまで気長にお待ちください。
