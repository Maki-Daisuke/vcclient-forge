VCClient Forge をご利用いただきありがとうございます。

----------------------------------------------------------------------
1. 起動方法
----------------------------------------------------------------------

※ cuda 版をご利用の場合（Windows / Linux 共通）:
   あらかじめ NVIDIA GPU ドライバを最新版へアップデートしてお使いください
   （CUDA 13 対応の R580 以降が必要です）。CUDA Toolkit と cuDNN は同梱
   されているため、別途インストールする必要はありません。

Windows
-------

【デスクトップ版（おすすめ）】

"vcclient-forge.exe" をダブルクリックしてください。

【Web ブラウザ版】

"start.bat" をダブルクリックしてください。
ブラウザが自動的に開き、以下の URL にアクセスします:
http://localhost:18888/

macOS
-----

【デスクトップ版（おすすめ）】

初回起動時: このフォルダでターミナルを開き、以下を実行してください:

  sh MacStart.command

※2回目以降は、Finder から "MacStart.command" をダブルクリックするだけで起動できます

【Web ブラウザ版】

このフォルダでターミナルを開き、以下を実行してください: 

  ./start.sh

ブラウザが自動的に開き、以下の URL にアクセスします:
http://localhost:18888/

Ubuntu Linux
------------

【動作要件・依存ライブラリ】

- OS: Ubuntu 24.04 LTS 以降（glibc >= 2.39）
- 必要なシステムパッケージ:

  sudo apt-get update && sudo apt-get install -y libportaudio2 libwebkitgtk-6.0-4 7zip

【デスクトップ版（おすすめ）】

ターミナルで "./vcclient-forge" を実行してください。

【Web ブラウザ版】

ターミナルで "./start.sh" を実行してください。
ブラウザが自動的に開き、以下の URL にアクセスします:
http://localhost:18888/

----------------------------------------------------------------------
2. 従来のバージョン（w-okada v2.0.78）からのデータ移行
----------------------------------------------------------------------

これまでに使用していたモデルや設定を引き継ぐ場合は、元の v2.0.78 フォルダ
にある "settings" と "model_dir" フォルダを、このフォルダへそのまま
コピーしてください。

----------------------------------------------------------------------
3. 初回起動時のご注意
----------------------------------------------------------------------

初回起動時には、音声変換に必要なAIモジュール（ContentVec、ピッチ推定器など）
に加えて、サンプルRVCモデルも自動的にダウンロードされます。
通信環境によってはダウンロード完了まで数分程度お時間がかかりますので、
画面が開くまで気長にお待ちください。
